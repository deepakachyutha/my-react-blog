# Frontend – React (Vite)

This folder contains the React single-page application for the AI-Powered Blogging Platform.

## Development

cd frontend
npm install
npm run dev

## Build

npm run build

The production build is generated inside the `dist/` folder.

## Deployment

The static frontend build is deployed using GitHub Pages via the `gh-pages` branch.

Note:
The frontend expects a running backend for authentication and post APIs. In the public demo, backend endpoints are not deployed.
